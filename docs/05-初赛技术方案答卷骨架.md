## 1. 赛题理解与需求分析

- Pdist 在聚类/度量学习/目标跟踪中的业务位置（引用解读文，不要展开过长）。
- 形式化定义：输入 (N, M)，输出 N(N-1)/2，公式，p 分支语义。

## 3. 关键技术设计（每个小节 = 问题 → 设计 → 数据 → 归因）

### 3.1 按行切分与多核负载均衡
- 为什么按行而不是按输出对：行对循环复用整行数据、写回地址天然不冲突。
- 尾行均摊策略公式与验证数据（各核耗时方差）。

### 3.2 泛 p 幂运算的 ln+exp 变换
- 硬件无 x^p 指令 → `|d|^p = exp(p·ln|d|)`；`1/p` Host 预计算。
- 数据：ln+exp 与标量循环的对比、精度对比（FP32 中间计算前后误差）。
- p=0/1/2 走专用分支避免 ln/exp 开销，分支选择由 TilingKey 编译期确定（模板参数化，省 I-Cache miss）。

### 3.3 精度保障体系
- FP16 进 → FP32 算 → FP16 出；误差数据表（各 p × dtype）。
- 与原生 torch_npu FP32 结果的交叉验证（7.6e-6 量级）。

### 3.4 双缓冲流水与 UB 利用率
- Double Buffering 结构图（搬运/计算乒乓）；PMU 数据：UB 利用率从 X% → 80%+ 的过程记录。
- 每个 Alloc/Free 配对审查结论（507899 零告警）。

### 3.5 边界与非对齐处理
- Pad + Mask 机制；M=133177、非对齐 M=131、N=1 空输出等用例结果。

## 4. 性能优化历程与归因（评审最关注章节）

- 基线：原生 pdist FP32 (4096,512) p=2 ≈133ms、p=0 ≈2087ms（见 [results/baseline_native_20261020.md](../results/baseline_native_20261020.md)），各 p 耗时相同 → 说明原生未做 p 分支优化；FP16 原生精度差（p=1 差 0.125）→ 精度+速度双反超点。
- 优化轮次表（严格来自 results/ 归档，(4096,512) FP32 p=2 主参考，详见 [docs/06](06-第一轮实现与优化总结.md) / [docs/07](07-第二轮实现与优化总结.md)）：

| 轮次 | 单变量改动 | 优化前 | 优化后 | 归因 |
|---|---|---|---|---|
| R0 | 逐 pair 现搬两行基线 | – | 72.3ms | 每 pair 2 次读、3 次 DMA、逐元素写回 |
| R1 | 行 i 常驻 + j 行批量 TJ=8 + 双缓冲 + p 分派 | 72.3ms | 33.3ms | 读流量减半、DMA÷8、MTE2/V 重叠 |
| R2 | tile 化（i-block × j-tile 二维分块，j-tile 常驻 UB） | 33.3ms | **27.7ms** | 读流量再降 4x、对角单元零搬运、屏障 3→1 |

- 加速比汇总（vos/native，FP32 p=2）：R0 0.54x → R1 4.0x → **R2 4.8x**；p=0 病态回退场景 R2 达 49x。
- FP16 结果：原生 FP16 精度差（p=1 差 0.125）→ 本方案「FP16 进 / FP32 算 / FP16 出」精度反超（±1 ulp），同时给出绝对耗时（(4096,512) p=2 28.2ms vs native 128.2ms，4.5x）。
