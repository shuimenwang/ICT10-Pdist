# 问题排查与优化速查手册（比赛日随身版）

> 数据来源：昇腾算子开发 250 个错误案例统计 + pds.md
> 用法：先按「现象/错误码」定位条目，再按排查路径逐项执行。

## 1. 十二类错误速查表（按优先级）

| # | 问题 | 错误码/现象 | 占比 | 优先级 | 排查路径（按序执行） |
|---|---|---|---|---|---|
| 1 | 运算结果错误 | 误差 >1e-4 或全错 | 52.4% | 最高 | ① 查 FP16 是否未转 FP32（ln/exp 精度崩）② 打印 Tiling 结构体验证切分 ③ Dump Tensor 定位偏差步 ④ CPU 模式单步对拍 ⑤ 查多核 index_id 写回冲突、p=0 置 0/置 1 遗漏 |
| 2 | 耗时超基线 | 无错误码，超时 | 9.2% | 次高 | ① msprof_op 查 UB 利用率（<80% 即不达标）② 查核间负载是否均衡 ③ 查标量计算是否阻塞向量流 |
| 3 | 输出内存异常 | 507899（内存无法释放） | 8.8% | 次高 | ① Alloc/Free 是否配对 ② 输出张量维度与结果是否匹配 ③ 核间汇总临时张量是否释放 |
| 4 | 访问无效地址 | 507015（核挂死 Core Dump） | 8.4% | 次高 | ① tlog 定位异常访问点 ② 验算 `src_addr + k` 偏移（重点非对齐场景）③ 核编号是否超物理核数 |
| 5 | 算子命名错误 | 找不到二进制文件 | 6.0% | 中 | 函数名 / 文件名 / Json 三处逐一比对 + 环境变量路径 |
| 6 | GM/UB 越界 | 多伴生 507015 | 5.2% | 中 | ① 打印 repeat_times / count_num 核对 UB 容量 ② Pad 长度与 Mask 有效性 ③ 切分块是否超 UB |
| 7 | 找不到 TilingKey | 31361001（Kernel 未找到） | 4.0% | 中 | Host 调用与 Kernel 定义逐位比对；确认配置已编译进二进制 |
| 8 | 执行超 30s 退出 | 脚本强杀 | 2.4% | 低 | ① 小数据复测区分死循环 vs 算量过大 ② 查 for_range 终止条件 ③ 加大切分粒度 |
| 9 | 地址未对齐 | 日志提示非 32B 对齐 | 1.2% | 低 | ① 打印访问地址验对齐 ② Pad 补齐是否到位、Mask 是否正确 ③ 异常检测工具直接定位指令 |
| 10 | 流同步超时 | 任务卡死 | 1.2% | 低 | 小数据正常 → 性能问题；小数据也卡 → 内存异常；查 Alloc/Free 配对与核间等待 |
| 11 | Host 段错误 | Segmentation fault | 0.8% | 低 | GDB 定位；查参数空指针（尤其可选参数 p 未传时）；核对 Tiling 函数参数计算 |
| 12 | 数据类型不支持 | int8 等未适配 | 0.4% | 低 | 对照赛题用例类型清单逐个适配，检查向量指令与类型匹配 |

## 2. 调试工具三件套

| 工具 | 用途 | 用法要点 |
|---|---|---|
| CPU 调试模式 | 结果错误 / 地址计算错误首选 | `export ASCEND_OPP_PATH=/usr/local/Ascend/ascend-toolkit/latest/opp` 后 `gdb --args python 测试脚本.py`，单步打印 UB/GM 地址与数值 |
| 日志分析 | Kernel 异常定位 | plog：`~/.mindstudio/logs/debug/plog*.log`，搜错误码 / `UB addr` / `repeat_times` / `core id`；tlog 辅助定位越界与对齐 |
| 异常检测工具 | 内存泄漏 / 越界 / 未对齐 | 编译时加检测参数，直接输出问题指令与地址，免人工翻日志 |

## 3. 性能优化三板斧（按优先级，禁止跳序）

### 第一板斧：Tiling（决定上限）

- [ ] 按特征维切块，多轮核内累加，避免跨 UB 搬运
- [ ] 多核负载均衡，尾数据均摊
- [ ] 块大小满足 32B 对齐（Pad + Mask）
- [ ] Pdist 专属：优先按行切分，各核处理连续多行

### 第二板斧：流水并行（打满流水线）

- [ ] Double Buffering：一块搬运、一块计算交替
- [ ] 核内完成累加与写回，避免核间同步
- [ ] 使用 T Pipe 自动同步，避免手动同步疏漏

### 第三板斧：代码细节（拉开差距）

- [ ] scalar（1/p、0、1）Host 预计算下发
- [ ] 模板参数替代运行时参数；高频分支前置（减少 I Cache Miss）
- [ ] 512B 对齐搬运；优先大块搬运 + Stride/Mask；利用 L2 Cache 缓存重复行向量
- [ ] ln+exp 幂运算指令合并；归约 add 指令配置适配行向量
